# Вырезки персонажей

PNG с прозрачным фоном, имена как у исходных артов в `public/assets/` (расширение `.png`).
Приложение берёт вырезку, если она есть, иначе исходный арт (`art(..., {cut:true})` в `src/ui/components.js`).

## Как сделано (всё локально, файлы никуда не отправлялись)
- Модель IS-Net из `@imgly/background-removal-node` 1.4.5 (модель внутри npm-пакета, работает офлайн; пакет стоял во временной папке, в проект не добавлен).
  `rembg` не использован: его модели скачиваются с GitHub Releases, а этот хост закрыт политикой сети окружения.
- `profile-hero` — нейросеть «просверлила» белое лицо на белом фоне, поэтому вырезан заливкой фона от краёв кадра со сглаживанием края.
- После вырезки: отсечение слабой полупрозрачности по краю (ореол), обрезка пустых полей, уменьшение до 900 px, палитровый PNG.
- Проверено на светлом (#F2F2F2), тёмном (#101014) и голубом фоне.
