# Арты

Положи сюда файлы с этими именами. Код менять не нужно: приложение само подхватит файлы при следующей сборке.
Если файла нет, на его месте будет тёмная заглушка той же формы. Можно использовать `.webp` с тем же именем, например `muscle-chest.webp`.

| Файл | Где используется | Рекомендуемый размер |
|---|---|---|
| `hero-home.png` | баннер главной, PNG с прозрачным фоном, персонаж выходит за верх баннера | 600×800 |
| `muscle-chest.jpg` | группа «Грудь» | 480×720 |
| `muscle-back.jpg` | группа «Спина» | 480×720 |
| `muscle-shoulders.jpg` | группа «Плечи» | 480×720 |
| `muscle-arms.jpg` | группы «Бицепс» и «Трицепс» | 480×720 |
| `muscle-legs.jpg` | группа «Ноги» | 480×720 |
| `muscle-core.jpg` | группа «Пресс» | 480×720 |
| `muscle-full.jpg` | группа «Многосуставные» (необязательно) | 480×720 |
| `rank-rookie.png` | ранг «До старта» | 400×460, прозрачный фон |
| `rank-start.png` | ранг «Старт» | 400×460, прозрачный фон |
| `rank-iron.png` | ранг «Новичок» | 400×460, прозрачный фон |
| `rank-steel.png` | ранг «Средний» | 400×460, прозрачный фон |
| `rank-titan.png` | ранг «Продвинутый» | 400×460, прозрачный фон |
| `rank-legend.png` | ранг «Элита» | 400×460, прозрачный фон |
| `profile-hero.png` | карточка профиля, PNG с прозрачным фоном | 500×700 |

Держи каждый файл до ~300 КБ (webp помогает): все арты кэшируются для офлайна.
